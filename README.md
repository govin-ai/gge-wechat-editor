### 📸 图片处理
- **智能粘贴**：截图、浏览器图片、文件均可直接粘贴
- **自动压缩**：图片自动压缩到合理大小
- **本地存储**：使用 IndexedDB 持久化存储，刷新不丢失
- **多图网格**：连续图片自动 2–3 列排版
- **公众号兼容**：复制时自动转为公众号可识别的格式

### 🚀 其他功能
- 实时预览、一键复制到公众号
- 从飞书、Notion、Word 等富文本粘贴自动转 Markdown
- 样式收藏、文章历史记录
- 支持 .md / .markdown 文件上传
- 响应式设计，适配桌面、平板、手机

## 📖 使用

### 本地运行
```bash
cd <项目目录>

# 启动本地服务器（Python）
python3 -m http.server 8080
# 或使用提供的脚本
./start.sh

# 访问 http://localhost:8080
```

纯静态站点，也可以部署到任意静态托管。部署到其他域名时，请同步修改 `index.html`、`guide.html`、`robots.txt` 和 `sitemap.xml` 中的站点网址。

### 使用步骤
1. 在右侧输入或粘贴 Markdown 内容（左侧为实时预览）
2. 选择喜欢的样式主题
3. 点击「复制到公众号」
4. 粘贴到微信公众号编辑器

## 🛠️ 技术栈

- **Vue 3** — 前端框架
- **markdown-it** — Markdown 解析
- **IndexedDB** — 本地图片持久化存储
- **Canvas API** — 客户端图片压缩

## 🎨 添加新样式

在 `styles.js` 的 `STYLES` 对象中新增一项，键名为样式 ID，`name` 为显示名称，`styles` 中需包含以下元素的内联 CSS：

`container`、`h1`–`h6`、`p`、`strong`、`em`、`a`、`ul`、`ol`、`li`、`blockquote`、`code`、`pre`、`hr`、`img`、`table`、`th`、`td`、`tr`

注意：微信公众号会过滤部分 CSS（如 `position`、外部字体、部分渐变），样式请尽量使用颜色、边框、背景色、内外边距等基础属性。
